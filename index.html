Ad Master Control (Single Location Setup)

Live ad control is centralized in AD_MASTER_CODES. Keys are numbered as 1,2,3,4... and each key maps automatically to assigned ad locations.

How it Works

You only paste ad code once in the central config. The script pushes that code to all target slot ids. No need to edit each section manually.

Smartlink + Popunder

Key 4 is Smartlink URL. Key 1 is Popunder URL/trigger config and runs on user click event.

Duplicate Placement Auto Sync

One code can feed multiple slots. Example: Native can appear in hero and formats section from the same key.

Safe Editing Rule

Only replace inside values of AD_MASTER_CODES. Keep keys and slot map unchanged for stable auto-rendering.
